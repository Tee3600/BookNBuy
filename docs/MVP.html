BookNBuy — MVP

Single-file MVP reference · Status: implemented (Phases 0–6), tsc clean

1. What it is

Unified marketplace: buy goods + book services on one account. NGN-first, diaspora-ready (pay in USD/GBP/EUR, vendors settle in NGN).

2. Stack

Next.js 14 App Router + TypeScript + Tailwind · Prisma + Postgres (local Docker) · Better Auth email+password · Paystack (cards, transfer, USSD, Apple Pay) · R2 photo storage · Termii SMS (log-first without key).

3. Money math (src/lib/fees.ts)

  • Commission: 8% products, 10% services, + ₦100 flat per order.
  • FX: NGN settlement; diaspora quote with 2% buffer, locked 30 min (unpaid orders expire via npm run order:expire).

5. State machines

  • Order: PENDING > PAID > FULFILLING > IN_TRANSIT > DELIVERED > COMPLETED | DISPUTED | REFUNDED | CANCELLED
  • Booking: PENDING_PAYMENT > CONFIRMED > COMPLETED | CANCELLED | NO_SHOW
  • Escrow: HELD > RELEASED | REFUNDED | PARTIAL; auto-release after 72h via npm run escrow:release (skips DISPUTED).

6. Run (local-first)

  1. docker compose up -d db
  2. Copy .env.example → .env; set BETTER_AUTH_SECRET (32+ chars), R2 keys, Paystack keys for live checkout.
  3. npm install · npx prisma migrate dev --name init · npm run db:seed · npm run dev
  4. Without DB the app renders demo-fallback data; money writes return 503.

7. Hardening (in MVP)

Rate limits (20/min on checkout/bookings/disputes/onboard), approved-vendor guards + x-admin-key when set, webhook HMAC enforced, mobile 480px rules.

8. Out of scope (post-MVP)

Native apps, live GPS, automated Paystack Transfers, multi-currency settlement, in-app chat, promos, courier APIs, recommendations, Redis rate limits, editable commission config.
